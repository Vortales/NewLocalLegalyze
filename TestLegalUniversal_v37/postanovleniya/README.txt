Папка для сформированных постановлений (всё локально).

v36: это ВЫБРАННАЯ папка (по умолчанию — рядом с программой). Сюда кладётся
готовый PNG, собранный из ответа ИИ:

    <номер>.png                    — постановление ИЗ ОТВЕТА ИИ (A4, 200 dpi)

Рядом — папка документа с материалами:

    <номер>/Заявка (отправлено в чат).txt  — ровно тот .txt, который ушёл в чат
    <номер>/ИИ-ответ.txt                   — ответ ИИ как есть (с разметкой)
    <номер>/ИИ-документ.txt                — бланк словами: что напечатано в PNG
    <номер>/ИИ-поля.json                   — разобранные поля
    <номер>/Проверка.txt                   — замечания по уставу (если есть)
    <номер>/<номер>.png                    — копия готового PNG

Порядок работы:

    ввод данных → «Сформировать» → (PNG пока НЕТ, в чат ушла заявка) →
    ответ ИИ → ИИ-ответ.txt → PNG из этого файла → проверка по уставу.

ПРОВЕРКА ПО УСТАВУ (v34). После сборки PNG клиент сверяет документ с уставом
и, если есть замечания, показывает их и пишет Проверка.txt:

  • взыскание должно входить в вилку, указанную у каждого пункта устава
    «[ Строгий выговор / Понижение / Увольнение ]» (пересечение по всем
    указанным пунктам);
  • процессуальный кодекс не является основанием дисциплинарного взыскания;
  • чёрный список — только по п. 4.5 (3 строгих выговора или несдача
    переаттестации);
  • понижение — только Шериф, его заместители и Ассистент Шерифа (п. 4.4);
  • несуществующие пункты устава отмечаются отдельно.

Печать департамента в бланке уменьшена вдвое и не налезает на текст.

Служебные файлы: *.json — история заполнений («Документы» → История).
Предпросмотр пишется во временную папку системы.


ПОСТАНОВЛЕНИЯ ПРОКУРОРА (v36)
------------------------------
«Документы» → «Постановление Прокурора». Бланк Офиса Генерального
прокурора: герб data/gerb_gov.png, печать data/stamp_gov.png,
шапка STATE OF SAN-ANDREAS / OFFICE OF THE ATTORNEY GENERAL,
«ПОСТАНОВЛЕНИЕ № AG-…», разделы «УСТАНОВИЛ» и «ПОСТАНОВИЛ».

Файлы в папке документа те же: заявка, ИИ-ответ.txt, ИИ-документ.txt,
ИИ-поля.json и Проверка.txt (там — замечания: сроки больше 72 часов,
отказ без основания из ст. 16 Регламента, нет порядка обжалования,
внеигровые термины IC/OOC).
