Папка для сформированных постановлений (всё локально).

v30.2: это ЕДИНСТВЕННАЯ папка, куда пишутся результаты. Рядом с программой
(или в папку, выбранную в форме) — и никогда в %APPDATA% и не на рабочий стол.

Каждое постановление лежит в своей папке postanovleniya/<номер>/:

    Заявка (отправлено в чат).txt  — ровно тот .txt, который ушёл в чат
    Заявка-поля.json               — поля формы на момент отправки
    ИИ-ответ.txt                   — ответ ИИ как есть (с разметкой)
    ИИ-ответ (не разобран).txt     — если ИИ не прислал блок постановления
    ИИ-поля.json                   — что клиент разобрал из ответа
    ИИ-документ.txt                — РОВНО тот бланк, который печатается в PNG
    <номер>.png                    — готовый бланк (A4, 200 dpi)

ВАЖНО: PNG печатается ТОЛЬКО из ответа ИИ. Кнопка «Сформировать» бланк не
печатает — она готовит заявку для чата. Если ИИ не прислал постановление,
PNG не появится; вместо него будет ИИ-ответ.txt для разбора.

Служебные файлы:

    *.json     — история заполнений: «Документы» → История → Загрузить в форму

Предпросмотр в форму не пишется: картинки идут во временную папку системы.
