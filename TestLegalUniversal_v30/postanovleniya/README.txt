Папка для сформированных постановлений (всё локально).

Каждая выдача лежит в своей папке postanovleniya/<номер>/:

    Заявка (отправлено в чат).txt  — ровно тот .txt, который ушёл в чат
    Заявка-поля.json               — поля формы на момент отправки
    ИИ-ответ.txt                   — ответ ИИ как есть (с разметкой)
    ИИ-ответ (не разобран).txt     — если ИИ прислал описание картинки/иное
    ИИ-поля.json                   — что клиент разобрал из ответа
    ИИ-документ.txt                — структура, принятая к печати
    <номер>.png                    — готовый бланк (A4, 200 dpi)

Служебные папки:

    *.json     — история заполнений: «Документы» → История → Загрузить в форму
    chat/      — файл-заявка, который прикрепляется к чату
    png/       — сюда пишутся PNG, если папка не выбрана в форме
    preview/   — картинки из кнопки «Предпросмотр»

Папку для PNG можно выбрать в самой форме — тогда путь запоминается в
config.json (postanovlenie_dir).
