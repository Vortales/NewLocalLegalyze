Папка для сформированных постановлений (всё локально).

    *.json   — история заполнений: «Документы» → История → Загрузить в форму
    chat/    — файл-заявка «ПОСТАНОВЛЕНИЕ <номер>.txt», который уходит в чат
    png/     — готовые постановления (A4, 200 dpi); многостраничные — «— стр.N»
    preview/ — картинки из кнопки «Предпросмотр»

Папку можно чистить — приложение создаст её заново.
