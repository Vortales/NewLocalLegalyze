Сюда можно положить рукописный шрифт для подписи в постановлении.

Поддерживаемые имена файлов (достаточно любого одного):

    Caveat-Regular.ttf
    Caveat.ttf
    GreatVibes-Regular.ttf
    GreatVibes.ttf
    MarckScript-Regular.ttf
    Pacifico-Regular.ttf
    BadScript-Regular.ttf

Пока файла нет, подпись рисуется наклонным DejaVu Serif — аккуратно, но
не «от руки». Код ищет шрифт сам, править ничего не нужно.
