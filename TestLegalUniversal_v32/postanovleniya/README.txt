Папка для сформированных постановлений (всё локально).

v32: это ВЫБРАННАЯ папка (по умолчанию — рядом с программой). Сюда кладётся
готовый PNG, собранный из ответа ИИ:

    <номер>.png                    — постановление ИЗ ОТВЕТА ИИ (A4, 200 dpi)

Рядом — папка документа с материалами:

    <номер>/Заявка (отправлено в чат).txt  — ровно тот .txt, который ушёл в чат
    <номер>/ИИ-ответ.txt                   — ответ ИИ как есть (с разметкой)
    <номер>/ИИ-документ.txt                — бланк словами: что напечатано в PNG
    <номер>/ИИ-поля.json                   — разобранные поля
    <номер>/<номер>.png                    — копия готового PNG

Порядок работы:

    ввод данных → «Сформировать» → (PNG пока НЕТ, в чат ушла заявка) →
    ответ ИИ → ИИ-ответ.txt → PNG из этого файла.

Документом считается ответ, в котором есть НАСТОЯЩИЕ поля («Ведомство:»,
«Номер:», «В отношении:», «Взыскание:» …) — от двух полей. Одни маркеры
===ПОСТАНОВЛЕНИЕ=== документом не считаются: именно на этом клиент ошибался
и выдавал «Бланк не сформирован».

Если полей нет, PNG не появляется: рядом остаётся ИИ-ответ.txt для разбора,
а клиент продолжает ждать настоящий ответ ИИ.

Если выбранная папка недоступна для записи (права Windows), файлы пишутся в
postanovleniya рядом с программой — об этом есть запись в логе.

Служебные файлы: *.json — история заполнений («Документы» → История).
Предпросмотр пишется во временную папку системы.
