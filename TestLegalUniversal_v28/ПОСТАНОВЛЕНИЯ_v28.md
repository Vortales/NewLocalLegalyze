# Постановления v28 — что работает и что учтено из замечаний

Документ описывает, как устроена функция постановлений в v28, что именно
исправлено по вашим замечаниям к v27 и что осталось согласовать.

---

## 0. Замечания к v27 — что сделано в v28

| Замечание (из `Замечания/Замечания.txt`) | Что сделано |
|---|---|
| В документе мусор: «Перейти к основному контенту», `Memphis.pdf`, `Шаблон.txt`, «Режим ИИ обрабатывает…» | Строки интерфейса отфильтровываются при разборе ответа; свободный текст идёт в «Обстоятельства», а не в «Дополнительно» |
| «Звание сотрудника: не указано», «Доказательства: не указаны» | Значения-заглушки считаются пустыми и в документ не попадают |
| Заголовок «о снятии взыскания», а пункт 1 — «Назначить… взыскание» | Пункты согласуются с видом документа: снятие/проверка/отстранение/назначение |
| В чате дублировалось сообщение | Автоотправка выполняется ровно один раз на заявку |
| После постановления нужен перезапуск приложения | После сборки PNG клиент перезапускается сам (как кнопка «Перезагрузить») |
| В форме «Постановление» надписей не видно | Тёмный фон и контрастные подписи, как в остальных окнах |
| «Нарушение и взыскание» должно быть необязательным | Блок помечен «необязательно»; ИИ сам подбирает пункт устава и взыскание по обстоятельствам |
| Нужен выбор папки для PNG | Кнопка «Выбрать папку…», путь запоминается в `config.json` |
| Все данные должен корректировать ИИ | Промт `1.12`: раздел `[6]` требует приводить должности, пункты, взыскание и формулировки к официальному виду |
| Нужен более профессиональный шрифт | PT Serif (ParaType, OFL) для бланка, Caveat — рукописная подпись |
| Образец бланка не нужен | Макет оставлен как есть (+ герб, который не пропечатался в v27) |
| Пункты устава — как в LSCSD | Проверка по уставу LSCSD (`3.1`, `4.1`, `10.6`); перечень взысканий — п. 4.1 |
| Любой сотрудник IAD может подписывать | Проверки должности нет — подпись берётся из формы |
| Только LSCSD | Другие ведомства не добавлялись |

## 1. Как это работает сейчас

```
«Документы» → «Постановление»
      ↓
форма (данные из Шаблон.txt подставляются сами)
      ↓ «Сформировать»
ПОСТАНОВЛЕНИЕ LSCSD-IAD-141.txt  ─┐
Шаблон.txt                        ├─ три вложения в чат → автoотправка
PDF промта (promt 1.12)           ─┘
      ↓ ИИ отвечает по триггеру
===ПОСТАНОВЛЕНИЕ=== … ===КОНЕЦ ПОСТАНОВЛЕНИЯ=== … ===КОНЕЦ ОТВЕТА===
      ↓ разбор полей
LSCSD-IAD-141.png (A4, 200 dpi, многостраничный)
      ↓
история: postanovleniya/*.json — открыть, поправить, сформировать заново
```

Файлы:

| Файл | Что делает |
|---|---|
| `postanovlenie_data.py` | данные документа, разбор ответа ИИ по триггерам, история, чтение устава |
| `doc_render.py` | рендер A4 в PNG (герб, печать, подпись, страницы) |
| `postanovlenie_ui.py` | форма-конструктор (данные / история / предпросмотр / выбор папки) |
| `main.py` | кнопка «Документы», третье вложение, автoотправка, приём ответа |
| `data/gerb_lscsd.png`, `data/stamp_lscsd.png` | герб и печать LSCSD |
| `data/reestr/*.json` | устав, по которому проверяется пункт нарушения |
| `data/fonts/` | PT Serif (бланк) и Caveat/Marck Script (подпись) |

Промт: `Для новой версии/Текущий промт/promt 1.12.txt` (это 1.10 + раздел
`[6. РЕЖИМ ПОСТАНОВЛЕНИЯ]`). Промт 1.10 не изменён.

## 2. Что осталось согласовать

По замечаниям почти все вопросы сняты. Открытыми остались только те, что
зависят не от кода:

1. **Рукописный шрифт «под ваш вкус».** Сейчас подпись — Caveat. Если нужен
   другой (например, как в примерах LSPD IAD), достаточно положить `.ttf` в
   `data/fonts` — код подхватит его автоматически.
2. **Точные официальные наименования должностей** IAD (Кадет, Офицер,
   Детектив, Сержант, Лейтенант, Капитан, Куратор отдела…): ИИ приводит
   формулировки к официальному виду, но сверять ему не с чем — в базе нет
   списка должностей LSCSD. Если пришлёте перечень, форма сможет подсказывать
   его списком.
3. **Другие ведомства** (Военная полиция, Прокуратура) — по вашей команде
   «позже»: для них понадобятся свои герб, печать, устав и перечень взысканий.

## 3. Ограничения, которые известны и не скрываются

* Проверка «пункт есть в уставе» понимает формат LSCSD — «3.1», «4.1»,
  «10.6» (в уставе нет статей и частей). Если номер не найден, форма честно
  пишет «в уставе не найдено» и не подставляет норму сама. Для актов с другой
  нумерацией (например, «пункт 19) части 1 статьи а») проверка тоже работает,
  но требует, чтобы текст статьи был загружен в `data/reestr`.
* После сборки PNG клиент перезапускается сам: это осознанное решение по
  замечанию «после постановления перезапускай приложение».
* Автoотправка сообщения использует вставку текста в поле ввода страницы
  (`Input.insertText`) и ту же кнопку отправки, что и микрофон. Если
  поверхность сервиса изменится, отправку можно сделать вручную — заявка уже
  вложена в чат.
* История хранится локально в `postanovleniya/` рядом с `config.json`;
  ничего никуда не отправляется.
