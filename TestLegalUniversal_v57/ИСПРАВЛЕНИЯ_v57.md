# v57 — русская типографика итоговых PNG («Рекомендация.txt»)

Версия `2.13.0`, выпуск `universal-embedded-v57`, сборка `2.13.0.0`.
База — `TestLegalUniversal_v56`; старые папки не изменялись.

Замечание: «Сделай новую версию с учётом `Рекомендация.txt` для итоговых .png
документов в Документы».

## Что требовалось и что сделано

Рекомендация состоит из двух частей: **неразрывные связки** (что не должно
оставаться в конце строки) и **красная строка** (абзацный отступ).

### 1. Неразрывные связки — `doc_render._bind_flags()` / `_bind_chunks()`

Строка теперь режется не по пробелам, а по **кускам**, которые нельзя разорвать
(`_wrap_rows`, `_split`-логика). Связки бывают двух видов:

| Что | Куда привязано | Пример из документа |
|---|---|---|
| Предлоги 1–2 букв: в, к, о, с, у, во, до, за, из, ко, на, об, от, по, со | к следующему слову | «в отношении», «по существу», «на основании» |
| Союзы 1–2 букв: а, и, но, да, ни, то, же, бы | к следующему слову | «и ночь», «но не» |
| Частицы не, ни | к следующему слову | «не пришел», «ни разу» |
| Инициалы | друг к другу и к фамилии | «А. С. Пушкин» |
| Сокращения: г., гг., стр., рис., №, §, т., д., к., п., пп., ст., ч. и слова «пункт/статья/глава/часть» | к следующему слову | «№ 301», «стр. 15», «г. Лос-Сантос», «пункта 2.5» |
| Числа | к следующему слову/значку | «20 000 $», «50 %», «2026 г.» |
| Частицы после слова: бы, б, ли, ль, же, ж | к слову ПЕРЕД ними | «сделал бы», «вряд ли», «все же» |
| Тире (—, –) | к слову ПЕРЕД ним (и к следующему) | «Москва — столица», строка не начинается с тире |
| «и т. д.», «и т. п.», «и др.», «и пр.» | вся конструкция целиком | «документы и т. д.» |

Дополнительная защита: если неразрывный кусок оказался шире строки (частый
случай — «06.11.2026,» + предлог + длинное слово), он всё равно режется по
пробелам, чтобы текст не уехал за поля.

### 2. Красная строка — `RED_LINE_PX = 98`

1,25 см при 200 dpi (`round(1.25 / 2.54 * 200)`). Отступ есть **только у первой
строки абзаца**; при переносе абзаца на следующий лист остаток печатается без
отступа. Первая строка короче на величину отступа — `_wrap_rows(...,
first_width=...)`.

Отступ не ставится там, где текст выровнен по центру: заголовки, «УСТАНОВИЛ:»,
«ПОСТАНОВИЛ:», подпись, колонтитул.

**Решение пользователя по v57:** выбран **вариант 2 «all»** — отступ есть у
**ВСЕХ** абзацев основного текста, в том числе у вводной части сразу после
заголовка и у первого абзаца после «УСТАНОВИЛ:» (то есть исключения «gost» не
применяются). Прежний вариант «gost» (первый абзац после заголовка без отступа)
остался переключателем `RED_LINE_VARIANT = "gost"`.

Отступ и пустая строка между абзацами одновременно не применяются: между
абзацами основного текста теперь только отступ (отбивка осталась у пунктов
резолюции и между разделами).

## Выбранные варианты

| Настройка | Значение | Почему |
|---|---|---|
| `RED_LINE_VARIANT` | `"all"` | решение пользователя: отступ у ВСЕХ абзацев основного текста |
| `BIND_VARIANT` | `"always"` | ровно как в рекомендации: ни один предлог/союз/«№»/инициал не остаётся в конце строки |

В коде оставлены и другие варианты — для сравнения и на случай смены решения:

* `RED_LINE_VARIANT`: `"gost"` (первый абзац после заголовка без отступа),
  `"with_gaps"` (отступ + пустая строка);
* `BIND_VARIANT`: `"mixed"` (жёсткие связки держатся, предлоги могут уехать
  ради плотности), `"exception"` (любая связка рвётся, если строка «жидкая»).

Сравнение — папка `Примеры_v57/`:

* `Примеры_v57_красная_строка.png` — три варианта отступа на реальных
  `LSCSD-IAD-1` и `AG-2`;
* `Примеры_v57_связки_узкая_колонка.png` — три варианта строгости связок в
  узкой колонке (висячих слов: 0 / 2 / 3);
* `Примеры_v57_связки.png` — то же на полной ширине бланка;
* `готовые_варианты/` — итоговые PNG в выбранном варианте.

## Попутно исправлено

* **Пробелы в первой строке.** Когда появилась красная строка, первая строка
  абзаца перерисовывалась повторным переносом и теряла межсловные пробелы
  («ГражданинLordikClawобратился…»). Теперь строки считаются один раз
  (`_wrap_rows`) и рисуются как есть (`draw_rows`).
* **Лимит красной строки.** Сначала укороченный лимит применялся только к
  первому куску, поэтому первая строка всё равно доходила до правого поля и
  отступ «схлопывал» пробелы. Теперь лимит действует на всю первую строку.
* **Точка возможного переноса внутри куска.** Части куска склеены неразрывным
  пробелом и не рвутся.

## Проверки

`tests/test_v57_remarks.py` — 19 тестов:

* предлоги/союзы/частицы не оказываются последним словом строки (4 ширины
  колонки);
* «№» не висит отдельно, инициалы не висят, «стр./рис./г./т./д./к.» не висят,
  числа не висят;
* «бы/ли/же» не начинают строку, строка не начинается с тире, «и т. д.» —
  один кусок и не притягивает следующее слово;
* `RED_LINE_PX` = 1,25 см, варианты по умолчанию `all`/`always`;
* первая строка короче на отступ, строки не «жидкие» и не выходят за поля;
* отбивка зависит от варианта, первый абзац после заголовков — без отступа;
* реальный рендер постановления Прокурора: ни одного висячего слова;
* версия `2.13.0` и релиз `universal-embedded-v57`.

Полный прогон: **956 тестов, OK, 17 skipped**.
