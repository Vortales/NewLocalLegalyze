================================================================================
                    ЭТАЛОННЫЙ СИНТАКСИС СБОРКИ NUITKA (v42)
                 Режим: Standalone (папка с Legalyze.exe и библиотеками)
================================================================================

Данный синтаксис протестирован и оптимизирован для максимальной скорости запуска
(< 1 секунды), стабильности работы без прав администратора и полной корректности
всех модулей (PyQt6, CDP, шифрование, генерация PDF, сбор логов).

--------------------------------------------------------------------------------
0. БЫСТРЫЙ СТАРТ (рекомендуется)
--------------------------------------------------------------------------------

    powershell -NoProfile -ExecutionPolicy Bypass -File .\build_nuitka_standalone.ps1

Скрипт делает всё сам: проверяет Python/Nuitka, ВЫБИРАЕТ КОМПИЛЯТОР C
(MSVC при наличии Visual Studio, иначе --mingw64), собирает и проверяет, что
в папке сборки лежат герб, печать, шрифты и устав. Обёртка: .bat с тем же именем.

Ключи: -Msvc (только MSVC), -MinGW (только MinGW64), -Zig, -NoLto, -OneFile.

--------------------------------------------------------------------------------
1. КОМАНДА ВРУЧНУЮ ИЗ КОРНЯ ПАПКИ TestLegalUniversal_v42:
--------------------------------------------------------------------------------

python -m nuitka --mode=standalone --msvc=latest --lto=yes --enable-plugin=pyqt6 --windows-console-mode=disable --windows-icon-from-ico=icon.ico --include-package=requests --include-package=urllib3 --include-package=websocket --include-package=cryptography --include-package=fpdf --include-package=PIL --include-data-dir=data=data --nofollow-import-to=websocket.policyserver --nofollow-import-to=websocket.server --include-distribution-metadata=PyQt6 --include-distribution-metadata=PyQt6-Qt6 --include-distribution-metadata=PyQt6-WebEngine --include-distribution-metadata=requests --include-distribution-metadata=urllib3 --include-distribution-metadata=websocket-client --include-distribution-metadata=cryptography --include-distribution-metadata=fpdf2 --include-distribution-metadata=pillow --assume-yes-for-downloads --product-name=Legalyze --file-description="Legalyze" --company-name=Legalyze --file-version=2.7.0.0 --product-version=2.7.0.0 --copyright="Legalyze" --report=build/nuitka-report.xml --output-dir=build --output-filename=Legalyze.exe main.py

Без Visual Studio: замените --msvc=latest на --mingw64 (Python 3.12 и ниже)
или на --zig.

--------------------------------------------------------------------------------
1a. ЕСЛИ NUITKA ПИШЕТ "cannot locate suitable C compiler"
--------------------------------------------------------------------------------

Это ЕДИНСТВЕННАЯ причина прошлой неудачи — код и ключи были верные, упала
только сборка C-кода. Варианты:

  a) Visual Studio Build Tools: при установке отметить
     "Desktop development with C++" (компонент MSVC v143 + Windows SDK).
     ВАЖНО: запускать обычный PowerShell, НЕ "Developer PowerShell for VS" —
     Nuitka тогда не находит компилятор.

  b) Без Visual Studio: --mingw64 — Nuitka сама скачает MinGW64
     (работает для Python 3.12 и ниже; для 3.13+ только MSVC или zig).

  c) --zig — Nuitka скачает zig, работает для 64-битного Python.

Проверка, что компилятор виден:
    "C:\Program Files (x86)\Microsoft Visual Studio\Installer\vswhere.exe" -latest -products * -requires Microsoft.VisualStudio.Component.VC.Tools.x86.x64 -property installationPath

--------------------------------------------------------------------------------
1b. ЧТО ИСПРАВЛЕНО В КЛЮЧАХ v35–v37
--------------------------------------------------------------------------------

* --include-data-dir=data=data  ВМЕСТО отдельных --include-data-files.
  Раньше копировались только DejaVuSans.ttf и лицензия: в сборке НЕ было
  data\gerb_lscsd.png, data\stamp_lscsd.png, data\fonts\*.ttf и
  data\reestr\*.json. В exe это значит: нет герба и печати в постановлении,
  нет рукописной подписи, и проверка постановления по уставу не работает
  (устав не найден). Теперь едет вся папка data целиком.

* --include-package=urllib3 и --include-package=PIL — используются
  неявно (requests/Pillow), чтобы не зависеть от анализа импортов.

* --nofollow-import-to=websocket.policyserver / websocket.server — именно они
  давали предупреждения "Cannot follow import ... SyntaxError" (эти модули
  серверные и клиенту не нужны).

* --nofollow-import-to=PIL.ImageTk / tkinter — убирают предупреждение
  anti-bloat про Tk (и лишний вес).

* --include-distribution-metadata=pillow — добавлено (Pillow тоже читает
  свои метаданные).

* Собственные модули (postanovlenie_data, postanovlenie_ui, doc_render,
  native_browser, win32_*) включены явно — подстраховка на случай
  динамических импортов.

* Версия продукта поднята до 2.7.0.0 (v50 → v51).

* Добавлены модули постановлений Прокурора (postanovlenie_prokuror_data,
  postanovlenie_prokuror_ui) и проверка наличия data\gerb_gov.png и
  data\stamp_gov.png — герб и печать Офиса Генерального прокурора.

Эти предупреждения БЕЗОПАСНЫ и не мешают сборке:
  * "Should decide '--prefer-source-code' vs ... fontTools" — fontTools
    подтягивает Pillow, работает и так;
  * "anti-bloat: Not including 'PIL.ImageTk'" — так и задумано;
  * "pyqt6: Support for PyQt6 is not perfect ... Qt threading" —
    у нас потоковая работа идёт через QThread/сигналы, проверено на v25–v34.

--------------------------------------------------------------------------------
2. РАЗБОР КЛЮЧЕЙ И АНАЛИЗ КОРРЕКТНОСТИ:
--------------------------------------------------------------------------------

* --mode=standalone
  Создаёт папку со всеми скомпилированными бинарниками и DLL (в отличие от
  onefile, который при КАЖДОМ запуске распаковывает 150 МБ в %TEMP%, нагружая
  диск и вызывая задержку 4-7 секунд). В режиме standalone запуск мгновенный.

* --msvc=latest --lto=yes
  Использует оптимизатор компилятора Microsoft Visual C++ и межмодульную
  оптимизацию (Link-Time Optimization) для максимальной производительности C-кода.

* --enable-plugin=pyqt6
  Штатный плагин Nuitka для PyQt6: автоматически собирает необходимые плагины
  платформы Qt (qwindows.dll, стили, шрифты).

* --windows-console-mode=disable
  Отключает появление чёрной консоли при старте.

* --windows-icon-from-ico=icon.ico
  Вшивает официальную иконку в Legalyze.exe.

* --include-package=requests,websocket,cryptography,fpdf
  Включает пакеты целиком с их внутренними подмодулями, предотвращая ошибки
  динамического импорта во время работы программы.

* --include-distribution-metadata=...
  Обязательно для библиотек, проверяющих свои версии через importlib.metadata
  (requests, urllib3, cryptography, PyQt6).

* --include-data-dir=data=data
  Копирует ВСЮ папку data (шрифты, герб, печать, устав в reestr/) внутрь
  папки сборки. В v26 здесь были только шрифт и лицензия — из-за этого в
  собранной программе не находились герб, печать и устав.

* --output-dir=build --output-filename=Legalyze.exe
  Результат сборки помещается в папку build\Legalyze.dist\Legalyze.exe.

--------------------------------------------------------------------------------
3. РЕЗУЛЬТАТ:
--------------------------------------------------------------------------------
После завершения компиляции готовое приложение находится в:
  build\Legalyze.dist\
Для запуска достаточно запустить Legalyze.exe внутри этой папки.
Папку Legalyze.dist можно переносить на любые другие компьютеры с Windows 10/11.
