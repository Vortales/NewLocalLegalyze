# v59 — выравнивание текста по ширине в итоговых PNG

Версия `2.15.0`, выпуск `universal-embedded-v59`, сборка `2.15.0.0`.
База — `TestLegalUniversal_v58`; старые папки не изменялись.

Замечание: «внутри документов .png выравнивай текст по ширине».

## 1. Что было не так

Выравнивание по ширине существует с v33, но пробел разрешалось растянуть
максимум в **2.6 раза** (`natural * 2.6`). При полосе набора 1354 px и обычном
пробеле 7 px это 18.2 px — на строках с малым числом пробелов места не
хватало, и строка не доходила до правого поля.

Замер по реальному `AG-2` (абзац «УСТАНОВИЛ», 22 строки):

| | v58 |
|---|---|
| строк, не доходящих до правого поля | **9 из 22** |
| худший недобор | **122 px** (нужен пробел 31.8 px, разрешено 18.2) |
| максимальная растяжка пробела | ×2.6 |

Визуально правый край оставался «рваным», хотя формально текст считался
выровненным.

## 2. Что сделано

### Перебалансировка строк — `_rebalance()`

Перед растяжкой пробелов строки выравниваются по плотности:

1. если пробел пришлось бы тянуть сильнее `SPACE_STRETCH_LIMIT` (×3.2),
   строка забирает слово из следующей;
2. если пробел пришлось бы наоборот сжимать (меньше ×0.55), строка отдаёт своё
   последнее слово вперёд;
3. переносится только **целый кусок** — неразрывные связки v57 сохраняются
   («к обращению» уезжает целиком, предлог не остаётся в конце строки);
4. если целый кусок не влезает, а строка осталась бы «жидкой», кусок делится
   по границе слова — но так, чтобы служебное слово не оказалось последним
   в строке.

Первая строка абзаца считается по укороченной ширине (минус красная строка).
Без этого она наполнялась до полной ширины, при отрисовке места не хватало, и
пробелы «схлопывались» — на выгрузке это выглядело как
«ГражданинLordikClawобратился…».

### Растяжка до поля — `draw_rows` / `draw_justified`

* потолок поднят до `SPACE_HARD_LIMIT` (×4.5) и работает только как страховка;
* снизу пробел не может схлопнуться меньше ×0.6;
* строки уже перебалансированы, поэтому обычно пробел раскладывается ровно до
  правого поля.

### Правила, которые не изменились

| Правило | Значение |
|---|---|
| последняя строка абзаца | по левому краю (`JUSTIFY_LAST_LINE = False`) |
| строка из одного слова | не растягивается |
| заголовки, «УСТАНОВИЛ:», «ПОСТАНОВИЛ:», подпись, колонтитул | по центру / справа |
| неразрывные связки (v57) | соблюдаются, перенос только целыми кусками |
| красная строка 1,25 см (v57) | без изменений |

## 3. Результат на реальном документе

|---|---|---|
| строк без выравнивания (AG-2) | 9 из 22 | **0 из 22** |
| максимальная растяжка пробела | ×2.6 (не хватало) | ×4.5 (страховка) |
| схлопывание пробелов в первой строке | было | исправлено |

## 4. Проверки

`tests/test_v59_justify.py` — 14 тестов:

* каждая строка, кроме последней, доходит до правого поля;
* ни одна строка не выходит за поле;
* пробел не «взрывается» и не схлопывается (границы ×0.5 … ×4.5);
* в строке обычные одиночные пробелы — ни NBSP, ни «ГражданинLordik»;
* перебалансировка не добавляет и не теряет слова;
* первая строка считается по укороченной ширине;
* потолок ×2.6 удалён из отрисовки;
* центрированные элементы (заголовки, подпись, колонтитул) не тронуты;
* на реальном `AG-2`: строк без выравнивания нет;
* версия `2.15.0` и релиз `universal-embedded-v59`.
